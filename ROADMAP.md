# Python Roadmap: Beginner to Advanced

Every lesson follows the same loop:
**concept → why it matters → example → line-by-line → exercise → challenge → hints → review → senior-dev refactor**

We move on only when the current topic is solid. Earlier topics get revisited in quick retention quizzes and debugging drills.

---

## Phase 1: Python Fundamentals (`01_fundamentals/`)

| # | Lesson | Key ideas |
|---|---|---|
| 1 | What Python is & how it runs | interpreter, `.py` files, `print()`, comments |
| 2 | Variables & data types | names, assignment, `int`, `float`, `str`, `bool`, `None`, `type()` |
| 3 | Strings & numbers | f-strings, slicing, string methods, int/float math, conversion |
| 4 | Operators | arithmetic, comparison, logical, assignment, `//` `%` `**` |
| 5 | Input & output | `input()`, converting input, formatted output |
| 6 | Conditions | `if` / `elif` / `else`, truthiness, indentation |
| 7 | Loops | `for`, `while`, `range()`, `break`, `continue` |
| 8 | Functions | `def`, parameters, `return`, default args, scope |
| 9 | Collections | lists, tuples, sets, dictionaries |

**🛠 Phase 1 Project:** command-line **Calculator** + **Expense Tracker** (menu, input validation, totals by category)
